Fair Value

A plainer, brighter read on the same ledger: crisp graphite ink on a soft slate paper, a confident cobalt signal in place of the muted steel, and every number set at full size in a clean tabular mono — no cells, no gimmicks. The number carries the design on its own.

Color

Light is the primary mode this time, not an afterthought: a soft slate-white paper, graphite ink instead of flat black, and one vivid cobalt signal for the single primary action or active state on a screen. Dark mode is a neutral graphite, not a tinted "vault" — same restraint, different ground. Gain and loss stay a separate pair, reserved for performance only.

Typography

Three roles. JetBrains Mono carries every price, share count, date and percentage in true tabular figures, set plainly at full size — no beveled cells, no novelty, just a clean precise face doing the one job this app actually has. Space Grotesk handles titles and controls; Public Sans is the quiet body face for names and explanatory copy.

Signature

The one bold move, restrained rather than novel: every hero figure sits on a calibration line — a ruled tick scale with a single cobalt mark showing where today sits against the recent range. The number itself stays plain and confident; the one flourish underneath it is doing real work, not decoration.
